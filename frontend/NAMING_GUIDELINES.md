# Naming Guidelines

## Components
- PascalCase
- Example: UserProfile.tsx

## Hooks
- camelCase with prefix use
- Example: useAuth.ts

## Utils
- camelCase
- Example: formatDate.ts

## Constants
- SCREAMING_SNAKE_CASE
- Example: API_BASE_URL

## Types
- PascalCase
- Example: UserData, UserProps

## Files
- Components: PascalCase.tsx
- Other files: camelCase.ts
